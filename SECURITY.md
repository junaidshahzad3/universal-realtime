# Security Policy

## Supported Versions

We actively provide security updates and patches for the following versions:

| Version | Supported |
| ------- | --------- |
| 1.2.x   | Yes       |
| 1.1.x   | Yes       |
| < 1.1.0 | No        |

## Reporting a Vulnerability

We take the security of `universal-realtime` seriously. If you find a security vulnerability, please do not open a public issue. Instead, report it directly through the following process:

1. Send an email to **junaidshahzad3@gmail.com** (or your preferred security contact email) describing the vulnerability.
2. Include details on how to reproduce the issue, along with any relevant code snippets or payloads.
3. We will acknowledge receipt of your report within 48 hours and work with you to coordinate a secure patch release.
